** How to install
*** Setup
1. change =my-username= to your username in =default.nix=

*** With Nix
1. use nix-shell to install nix-darwin.
2. use shell alias install to apply config.

#+begin_src zsh
  nix-shell
  install
#+end_src

*** Without Nix
Link individual config. Take emacs config as exmple.
#+begin_src zsh
  ln -s ./emacs/init.el ~/.emacs.d/init.el
#+end_src
